# 06. If-Else Branching

## Rules for Go `if`:
1. No parentheses `( )` around the condition.
2. Curly braces `{ }` are strictly mandatory!
3. `else` must sit on the exact same line as the closing `}`.
4. **Short Statement in `if`:** `if x := calculate(); x > 0 { ... }` limits `x` strictly to the `if-else` blocks.
