# 🚀 Go with Taqui — Pedagogy Upgrade Tracker

This document tracks the systematic upgrade of all 55 modules in **Go with Taqui** to the new **World-Class 6-Step Beginner Pedagogy Standard**.

---

## 🎯 The Gold Standard 6-Step Learning Flow

Every upgraded lesson must strictly follow this linear progression:
1. **STEP 1 — Plain-English "What Is This?" Banner**: 2 sentences an 8th grader understands immediately (zero code), 1 big real-world analogy card, and inline `<Term>` vocabulary pills.
2. **STEP 2 — "Why Do We Care?"**: The real-world catastrophe that occurs when this Go feature is missing.
3. **STEP 3 — Numbered Sub-Topic Deep Dives (One Concept at a Time)**:
   - **A. Simple Meaning + Analogy**: Max 3 lines.
   - **B. Interactive Story Lab**: Built with `<StepSimulatorShell>` featuring step-forward, slow auto-play, live speech bubble teacher narrator, and synchronized Go code line highlighting.
   - **C. Line-by-Line Code Card**: Runnable Go code with clickable line annotations and a toggleable JavaScript Mental Model bridge.
   - **D. 1-Question "Did It Click?" Micro-Check**: Instant reasoning for right/wrong options.
4. **STEP 4 — Common Beginner Traps ("Don't Do This!")**: 3 side-by-side ❌ Broken vs ✅ Fixed code cards.
5. **STEP 5 — 1-Glance Memory Cheat Sheet**: 5 compact bullet rules summarizing the whole topic.
6. **STEP 6 — Subtopics Checklist & Progress Integration**: LocalStorage sync with seamless fallback.
