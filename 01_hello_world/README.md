# 01. Hello World in Go

Every standalone Go application starts with an entry point: `package main` and `func main()`.

## Key Concepts
* `package main`: Tells the Go compiler this file should be compiled into an executable binary, not a shared library.
* `import "fmt"`: Imports the standard "format" package for printing and I/O.
* `func main()`: The execution starting point of every Go application.

## How to Run
```bash
go run main.go
```
